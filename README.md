# Ticlone 🎬

**Лучшая альтернатива TikTok с душой!**

## Что это?
Ticlone - это социальная платформа для коротких видео, созданная в Turbowarp.

## Уникальные фичи:
- 🎚️ Настройка скорости видео при публикации (0.1x-5x)
- 💝 Дружеское сообщество
- 🔒 Уважение к приватности

## Как использовать:

1. Загрузи видео через интерфейс публикации
2. Придумай название
3. Придумай описание
4. Установи скорость воспроизведения по умолчанию
5. Добавь теги
6. Нажимай на кнопку **опубликовать**
7. Готово!

Или просто наслаждайся просмотром!

## Технологии:
- Turbowarp
- GitHub API для хранения данных
